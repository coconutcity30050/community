# Title : "新竹市椰城社區"

## Design Methods
1. use html & javascript to design the webpage index.html
2. create dropdown menu from the folers in ./content
3. to convert markdown into html with https://cdnjs.cloudflare.com/ajax/libs/showdown/2.1.0/showdown.min.js
4. every webpage use Traditional Chinese
5. every webpage has its own background image .jpg stored in ./images
6. support Responsive Web Design

### The dropdown menu listed below
* 管理委員會: 成員職掌，社區行事歷 
* 法條規約: 中央法規，社區規約
* 共用場所: 中庭區域，警衛室，辦公室，閱覽室，包裹室
* 社區設備: 機電機房，污水機房, 消防及警報設備
* 清潔環保: 環保局回收班表，垃圾回收須知。
