# Title : "新竹市椰城社區"

## Design Methods
1. use html & javascript to design the webpage index.html
2. create dropdown menu from the folers in ./content
3. to convert markdown into html with https://cdnjs.cloudflare.com/ajax/libs/showdown/2.1.0/showdown.min.js
4. visit webpage requires to login Email/password
5. every webpage use Traditional Chinese
6. every webpage has its own background image .jpg stored in ./images
7. support Responsive Web Design
8. use Firebase database, user data including email, password, household, address.
reading Firebase database and authenticate with Email/pasword, and allow admin to do search, add, delete data, allow user to modify username & password

* 管理委員會: 成員職掌，會議記錄，區權會, 社區行事歷

* 法條規約: 中央法規，社區規約

* 社區設備: 機電機房，污水機房, 消防及警報設備, 保修行事曆
* 清潔環保: 選單項目: 清潔人員月班表，環保局回收周班表，垃圾回收須知。
